# Data

This project uses the Olist Brazilian E-Commerce Public Dataset, available on Kaggle.

## How to download

1. Download the SQLite version from: https://www.kaggle.com/datasets/terencicp/e-commerce-dataset-by-olist-as-an-sqlite-database
2. Unzip the download.
3. Place `olist.sqlite` in this `data/` directory.


## About the dataset

Real anonymised commercial data from Olist covering ~100k orders placed between 2016 and 2018. Contains 9 relational tables covering orders, customers, sellers, products, reviews, payments, and geolocation. References to companies and partners in review text have been replaced with names from Game of Thrones.
